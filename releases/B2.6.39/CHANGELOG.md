# HakoSpace B2.6.39

Release date: 2026-09-03 (UTC)

## Features

- Screen-share pop-out windows now support true fullscreen. Double-clicking a video pop-out previously triggered a plain window maximize that kept the taskbar visible; it now enters real fullscreen, with Esc or another double-click to exit. Both pop-out styles also gain a fullscreen toggle button in the control bar, and double-click toggles fullscreen in browser pop-out windows too. The stage pop-out keeps its standard maximize behavior. (#110)
- The "viewer boost active" success pill is now a brief 5-second toast instead of a permanent overlay — the title-bar badge remains as the always-on indicator while a boost is active, and warning states still show persistent pills. (#110)

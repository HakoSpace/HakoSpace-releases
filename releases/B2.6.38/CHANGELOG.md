# HakoSpace B2.6.38

Release date: 2026-09-03 (UTC)

## Bug Fixes

- The frameless screen-share pop-out window from the previous release was hard to move — its only drag handle was an invisible strip along the top edge. The entire window is now draggable: click and drag anywhere on the video, while the close button corner and the bottom control bar remain clickable. Double-click anywhere toggles maximize/restore, and right-click opens the system window menu. (#109)

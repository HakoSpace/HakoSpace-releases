# HakoSpace B2.6.47

Release date: 2026-09-27 (UTC)

This pre-release contains no changes to the desktop app, the server, the web client each server provides or the game HUD since B2.6.46; only the version number is new.

## Notes

- Desktop apps and servers on B2.6.46 look for updates on HakoSpace's own release source, dl.hakospace.com, first, and fall back to GitHub automatically when it cannot be reached or a download does not pass verification. This is the first release published since that change. Installs on B2.6.45 or earlier find this update on GitHub, as before.
- The Privacy Policy and the EULA are unchanged in this release (still effective 2026-09-26 and 2026-07-08), so no new acceptance is required.
- The HUD program bundled with the desktop app is the same build as in B2.6.46.
- No Docker image is published for this pre-release. Servers running the Docker image stay on their current version.
